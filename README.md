# Expense Tracker

A full-stack MERN expense management application with real-time analytics, REST APIs, and Docker containerization.

## Live Demo
https://expense-tracker-orpin-six.vercel.app

## Tech Stack
- **Frontend:** React.js, Recharts
- **Backend:** Node.js, Express.js, REST APIs
- **Database:** MongoDB
- **DevOps:** Docker, Kubernetes

## Features
- Transaction and category management (full CRUD)
- Interactive analytics dashboard with income/expense summaries
- Pagination and Recharts-based visualizations
- Containerized with Docker
- Kubernetes deployment manifests for scalable deployment

## Getting Started
```bash
git clone https://github.com/BarathDevLab/Expense_Tracker
cd Expense_Tracker
npm install
npm run dev
```

## Docker
```bash
docker-compose up
```
